# 双人房间对战

该版本使用 Game Studio 导出的画面及本机房间服务。两名玩家需在同一局域网内，且运行服务的电脑不能休眠或退出服务。

在仓库根目录运行：

```sh
HOST=0.0.0.0 PORT=3221 npm start
```

创建者和对方都使用运行服务的电脑的局域网 IPv4 地址打开页面，例如 `http://192.168.1.10:3221/`（地址请按本机实际情况填写，macOS 可用 `ipconfig getifaddr en0` 查询）。创建房间后点「邀请对手」，把分享或复制的链接发给对方；对方打开链接即可自动加入。仍可通过「加入房间」手动输入房间号。

邀请链接使用创建者当前的页面地址。如果创建者使用 `127.0.0.1` 或 `localhost`，该地址在对方设备上指向的是对方自己，无法加入；请先改用局域网 IP 打开页面再建房。对方需要能访问该地址和端口，跨互联网则需要双方可访问的 HTTPS 部署。浏览器不支持自动复制时，按弹窗提示手动复制链接。

链接中只有房间号，不含玩家身份令牌；知道链接的人可以占据对手席位，请谨慎分享。同一标签页刷新会尝试恢复身份，服务重启或房间已满时会显示提示。

一局结束后棋盘下方会出现「再来一局」，双方都点一次即可在同一房间重开一局，房间号和身份都不变；先点的一方会看到「等待对方同意」。

服务把房间保存在内存中，关闭或重启服务会丢失房间。房间号不等于账号系统，不应将此测试服务暴露到公网；跨互联网对战需要安全部署、HTTPS、域名及相应的服务器保护。

Game Studio 预览和离线 HTML 默认的安全策略禁止联网，请通过上述服务提供的页面进行房间对战；它们仍可用于人机练习与同屏双人。

更多部署方式（Docker、公网域名）见仓库根目录的 `README.md`。
