# 双人房间对战

该版本使用 Game Studio 导出的画面及本机房间服务。两名玩家需在同一局域网内，且运行服务的电脑不能休眠或退出服务。

在仓库根目录运行：

```sh
HOST=0.0.0.0 PORT=3221 npm start
```

在运行服务的电脑上打开 `http://127.0.0.1:3221/`；同一 Wi-Fi 的其他玩家使用这台电脑的局域网 IPv4 地址，例如 `http://192.168.1.10:3221/`。具体地址请按本机实际地址填写。创建房间后将房间号告诉对方，对方选择加入房间并输入房间号。

一局结束后棋盘下方会出现「再来一局」，双方都点一次即可在同一房间重开一局，房间号和身份都不变；先点的一方会看到「等待对方同意」。

服务把房间保存在内存中，关闭或重启服务会丢失房间。房间号不等于账号系统，不应将此测试服务暴露到公网；跨互联网对战需要安全部署、HTTPS、域名及相应的服务器保护。

Game Studio 预览和离线 HTML 默认的安全策略禁止联网，请通过上述服务提供的页面进行房间对战；它们仍可用于人机练习与同屏双人。

更多部署方式（Docker、公网域名）见仓库根目录的 `README.md`。
